# Mac 官网分享入口

## 为什么开发

用户需要从无线麦SayAll.app中快速把官网分享给其他人，而不必手动查找、输入或核对链接。

## 用户功能

- “关于 → 更新与支持”提供唯一分享入口，避免在统计页和侧边栏重复同一命令。
- 面板显示官网二维码、完整链接和“复制链接”按钮；复制成功或失败会在当前页面显示明确反馈。

## 范围与非目标

- 分享目标为项目现有本地化官网，安全追加或覆盖 `from=mac_share`。
- 二维码由 CoreImage 在本机生成，不请求二维码服务，不引入第三方依赖。
- 本次不增加系统分享 Sheet、Popover、账号邀请、奖励或分享统计上报。

## 关键设计与影响范围

- `AppSharing.swift` 是 canonical URL、二维码输入和剪贴板字符串的唯一来源。
- `SettingsView.swift` 只在关于页维护展开状态并复用 `ShareCard`，搜索“分享”会定位到该分区。
- 影响设置窗口的关于页与设置项搜索；不改变统计、连接、按键映射、语音、权限、更新、私有功能或服务端协议。
- “问题反馈”从状态栏迁移到关于页，固定反馈 URL 与最低权限边界不变。

## 隐私与兼容边界

分享链接只包含官网已有路径、已有查询参数和 `from=mac_share`。App 不记录链接、不上传点击、不读取剪贴板；只有用户点击“复制链接”时才写入系统剪贴板。二维码与复制内容严格来自同一个 URL。
